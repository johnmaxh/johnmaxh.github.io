# Max Hamilton’s research website

This Jekyll site presents Max Hamilton’s research in reliable AI measurement. The compact homepage uses tabs and expandable project stories.

## Run locally

With Jekyll installed, run `jekyll serve` from the repository root and open `http://localhost:4000`.

The homepage is in `index.html`, its layout is `_layouts/layout.html`, styles are in `static/css/site.css`, and the demo logic is in `static/js/site.js`. The demo uses a synthetic marsh scene divided into a fixed population of 48 regions. It compares uniform sampling without replacement with importance sampling without replacement using fixed predicted bird counts; it does not adapt the model or store responses.

The public page links to LinkedIn, Google Scholar, and GitHub.
